# C++ 学习练习 (cpp_learn)

记录 C++ 基础语法学习过程的练习代码，每个目录是一个独立的 Visual Studio 工程（`.slnx` + `.vcxproj`），可直接打开编译运行。

## 目录结构

| 目录 | 主题 |
| --- | --- |
| `03_01` ~ `03_06` | 基础入门、变量定义、标识符规则、表达式 |
| `04_01` ~ `04_08` | 数据类型、`sizeof`、字符与转义字符、布尔类型、输入输出 |
| `05_1_1` ~ `05_1_3` | 算术运算、强制类型转换、取模、自增自减 |
| `05_2` ~ `05_5` | 赋值运算符、比较与逻辑运算、逗号表达式 |
| `5_6_1` ~ `5_6_4` | 位运算：与、或、异或、按位取反 |
| `6_1` | 待补充 |

每个工程内只有 `main.cpp` 一个源文件，代码中保留了大量注释，用于说明语法要点。

## 编译环境

- **IDE**：Visual Studio（`v18` / 2022 及以上，工程文件为 `.slnx` 格式）
- **语言标准**：C++14 及以上
- **平台**：Windows x64 / Debug

打开任一目录下的 `*.slnx` 即可在 Visual Studio 中编译运行。

## 关于仓库

编译产物（`.vs/`、`x64/`、`Debug/`、`*.obj`、`*.exe`、`*.pdb` 等）已通过 `.gitignore` 排除，仓库中只保留源码与工程文件，克隆后体积很小。
